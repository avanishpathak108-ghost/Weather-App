# Frontend Lab Assignment - 3

Open each assignment's `index.html` file in your browser.

## Folders
1. `01-BMI-Calculator` — calculate BMI from height and weight.
2. `02-Signup-Form` — signup form with basic validation.
3. `03-Theme-Changer` — change the page color theme.
4. `04-Digital-Clock` — live digital clock.
5. `05-Todo-List` — add, delete, and complete tasks.

The code is intentionally simple and uses plain HTML, CSS, and JavaScript.
